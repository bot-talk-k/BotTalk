三步开始推送
扫码绑定，获取 SendKey，一行 HTTP 发消息。
1

选通道，扫码绑定

用飞书或微信扫码，30 秒完成注册，自动生成专属 SendKey。

2

获取 SendKey

登录后控制台首页即可看到，复制即用，无需任何配置。

3

一行 HTTP 发消息

用任意语言 GET 或 POST，消息秒达。兼容 Server酱 API 格式。

就这么简单
兼容 Server酱风格接口，切换零成本。
# GET 风格 (Server酱兼容)
curl "https://bot-talk.com/<SendKey>.send?title=部署完成&desp=服务已上线"

# POST 风格
curl -X POST "https://bot-talk.com/<SendKey>.send" \
  -d "title=部署完成&desp=服务已上线&channel=all"
import requests

requests.get("https://bot-talk.com/<SendKey>.send", params={
    "title": "部署完成",
    "desp":  "服务已上线",
})
// Node.js (fetch)
await fetch(`https://bot-talk.com/${sendKey}.send?title=部署完成&desp=服务已上线`)
