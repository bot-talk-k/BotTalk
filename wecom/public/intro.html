🏢 企业微信推送通道

HTTP 一行调用,消息直达企业微信智能机器人。
无条数限制 · 激活后无需回复 · 个人扫码即用。

扫码接入 / 进入控制台 ← BotTalk 官网

为什么用企业微信通道

✅ 无限发送 — 无 10 条限流,告警随便发
✅ 激活后无需回复 — 首次发一句话激活,之后单向接收
✅ 扫码即用 — 企业微信扫码一键创建机器人,零后台配置
✅ HTTP 任意语言 — curl / Python / Node.js / Go

发送一条消息只需

curl "https://bot-talk.com/YOUR_SENDKEY.send?title=部署完成&desp=服务已上线"

扫码绑定后会拿到你的 SendKey,替换上面的 YOUR_SENDKEY 即可。
